<h1>KeyboardSounds</h1>
<p>Plays keyboard sounds while you type, with multiple sound packs to choose from</p>

> [!IMPORTANT]  
> To add custom plugins, you need to build Vencord from source. Follow [this Guide](https://docs.vencord.dev/installing/) if you haven't done this yet

> [!NOTE]  
> This plugin only works on Discord Desktop and Vesktop, because it loads the sounds from this repository when it starts

## Installing
If you don't know how to install custom Plugins, follow [this Guide](https://docs.vencord.dev/installing/custom-plugins/)

Clone the plugin into a folder called `KeyboardSounds.desktop`. The `.desktop` ending tells Vencord to only build it for Discord Desktop and Vesktop:
```sh
git clone https://github.com/Domis-Vencord-Plugins/KeyboardSounds KeyboardSounds.desktop
```
